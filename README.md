# ChatGPT → VOICEVOX 読み上げ（0.7.6）

ChatGPTの応答をキャラクターごとにVOICEVOXで読み上げる、非公式のChrome拡張機能です。Ubuntu・Google Chromeで開発・動作確認しています。ChatGPTおよびVOICEVOXの公式製品ではありません。

## 主な機能

- 応答中に完成したセリフを発言順に合成・再生
- キャラクター名・略称・音声スタイルの認識
- 未登録の登場人物への自動配役、ナレーション、会話ごとの配役固定
- 一時停止・再開・セリフ単位のスキップ・全キャンセル・手動再生
- 話者の画像と名前、残り時間・再生ゲージを表示する右端パネル
- 音声出力機器の指定、VOICEVOX接続先の変更
- キャラクター画像付きメンバー一覧、スタイル選択と試聴
- 共通／会話別の発音辞書、記号に合わせた感情演出

## 必要なもの

- Google Chrome 116以降
- 起動済みのVOICEVOX Engine（既定の接続先は `http://127.0.0.1:50021`）
- `https://chatgpt.com/` の会話ページ

他OS・Chromium派生ブラウザーでの動作は未確認です。Chromeウェブストアでの配布を前提とせず、展開した拡張機能を手動で読み込みます。

## 導入・更新

1. このリポジトリのソースをダウンロードして展開します。配布用ZIPの場合も展開してください。
2. Chromeで `chrome://extensions/` を開き、「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` がある `chrome-extension/` フォルダーを選びます。拡張機能のみのZIPでは展開先の直下を選びます。
4. VOICEVOXを起動し、ChatGPTのページを開きます。
5. 更新時はファイルを置き換え、拡張機能とChatGPTのページを再読み込みしてください。設定画面も開き直してください。

ビルドやnpmパッケージのインストールは不要です。

## 読み上げる形式

```text
🟢ずんだもん「こんにちは。今日は何を話そうか？」
🔴めたん[ツンツン]「まずは音声の確認からですわ。」
🟣きりたん「こちらも聞こえていますか？」
```

絵文字とスタイル指定は省略できます。各発言を独立した行または段落にし、セリフを `「」` で閉じてください。「四国めたん→めたん」「東北きりたん→きりたん」などの略称に対応します。利用できる名前・スタイルは設定のメンバー一覧で確認できます。説明用のセリフ例はコードブロック内に書いてください。

カスタム指示の例は [custom-instructions.md](custom-instructions.md) にあります。設定の「使い方」から最小限の指示もコピーできます。静的な話者・スタイル一覧は例であり、実際に導入したVOICEVOXの一覧を優先してください。

## 基本操作

1. ChatGPTの会話ページで拡張機能のアイコンを押し、「自動読み上げ」をONにします。
2. 次のメッセージを送信すると、その応答の完成したセリフから読み上げます。ON以前の履歴は読みません。
3. 「一時停止／再開」で再生位置と待機中のセリフを保持します。
4. 「スキップ（1人分）」は現在のセリフ1件、「全キャンセル」はこのタブの再生中・待機中の全件を対象とします。自動読み上げのON／OFFは維持します。
5. 「停止・自動OFF」は再生を中止し、自動読み上げもOFFにします。

「直近の取得をもう一度読む」は取得済みのセリフを再生待ちへ追加します。「セリフを確認・選んで再生」では自動OFF時に対象を選択できます。ポップアップを閉じても再生は続きます。自動ON／OFFは全ChatGPTタブで共有しますが、再生操作は対象タブ単位です。

音声合成と再生は分離し、現在のセリフを再生しながら最大3件を先読みします。先読みは合成中・合成待ち・合成済みを合わせて3件までのキューとし、API通信は同時実行せず1件ずつ順番に処理します。停止時はそのタブの先読みも中断・破棄します。再生順は維持し、合成が間に合わない場合は完成を待って再生します。

VOICEVOX停止中は新しい合成を追加せず、起動監視を続けます。復帰後は新しい発言から再開し、停止中の履歴は読み返しません。

## キャラクターパネル

画像・小さなキャラクター名・残り時間とゲージ・操作ボタンを縦に表示します。画像は接続先VOICEVOXから取得し、Speakerが変わると右端へスライドして切り替えます。一時停止中は表示を維持します。

- ⏸️／▶️：一時停止・再開
- ⏭️：現在のセリフをスキップ
- ⏹️：このタブの再生を全キャンセル
- 左側の ◀／▶：引き出す・しまう。収納状態を保存します。
- 画像または左側タブを上下ドラッグ：位置を変更・保存

アドオンメニューの「キャラクターパネルを表示」でON／OFFを切り替えます。OFF中は引き出しタブも非表示になり、パネルの状態問い合わせを停止します。音声再生は続きます。

状態確認は再生・合成・再生待ちがある間は250ms、一時停止・待機中は2秒間隔です。待機状態からの表示開始には最大約2秒かかります。画像は話者単位で最大24件をメモリに保持し、古いものから破棄します。取得できない場合は 🎭、時間未確定時は `--:--` を表示します。独自画像の登録には未対応です。

## 設定

### 音声出力・接続先

ポップアップ右上の「設定」から開きます。音声出力機器を選んで保存すると、再生中のセリフにも反映します。「システムの既定」はOSの出力先に追従します。特定機器に固定したい場合は、その機器自体の項目を選んでください。

機器が使えない場合は一時的に既定出力へ戻し、理由を表示します。保存した希望の機器は維持し、再接続時に戻します。出力候補が不足するときは「機器一覧を更新」を押してください。マイク許可を求めることがありますが、取得したストリームは直ちに停止し、録音・送信しません。

別のPCやポートのVOICEVOXを使う場合は接続先URLを変更します。許可するのは選択した接続先のホストです。接続先を変えると、読み上げるテキストの送信先も変わります。

話者の事前チェックと、その結果に基づいて使用不能なスタイルを予め配役候補から除外する機能は一時停止しています。保存済みのチェック結果も配役には使いません。通常利用時の合成失敗では、同じ話者・同じセリフを2秒間隔で最大2回再試行します。すべて失敗した場合、ランダム配役は失敗した話者を除外して再抽選し、固定配役と抽選候補の枯渇はそのセリフだけをスキップして後続を続けます。

### 配役・試聴・辞書

- 配役：登場人物への自動割り当て、ナレーション、候補メンバー、別名、手動固定を設定できます。配役は会話ごとに保存します。
- メンバー：左に画像、右に名前・スタイル・試聴操作を表示します。検索とスタイル選択に対応します。画像は表示範囲に応じて取得します。
- 試聴：「試聴」を押すと確認用の音声が流れ、同じボタンが「停止」に切り替わります。試聴だけでは配役を保存しません。
- 発音辞書：1行ずつ `春雨=はるさめ` の形式で登録します。会話限定が共通辞書より優先されます。長い単語から置換し、置換結果は再置換しません。
- 感情演出：`！！`、`……`、`？` に応じた控えめな補正を行います。明示した `[スタイル名]` を優先します。

長いセリフは文字数に応じて1.00～1.60倍の話速を設定します。話者名・スタイル指定・空白を文字数に含めません。

## データと権限

[プライバシーと権限](docs/PRIVACY.md)に、通信先・保存データ・各権限の用途をまとめています。解析や音声合成のための独自の外部サービス、アクセス解析は使用していません。指定したVOICEVOXへ読み上げ用テキストを送ります。

## 制約・トラブルシューティング

- ChatGPTの画面構造が変わると取得処理の修正が必要になることがあります。
- 未完のセリフ、コード、引用、表、入力欄などは自動読み上げから除外します。未知の話者は自動配役設定によって扱いが変わります。
- 複数タブの音声は共通の再生処理で順番に処理します。一時停止したタブ以外の再生が進むことがあります。
- 設定を保存しても聞こえない場合は、ポップアップの再生エラー、Chromeの権限、OSの機器・音量・Bluetooth再生モードを確認してください。
- 取得本文・診断情報のコピーには会話内容や会話URLが含まれることがあります。Issue投稿前に確認し、個人情報を取り除いてください。

# プライバシーと権限

## 通信

拡張機能はChatGPTの表示済み会話をページ内で取得・解析します。ChatGPTへのログイン情報やCookieを読み取る処理はありません。

読み上げ対象のテキスト（発音辞書適用後）と音声スタイルIDを、設定したVOICEVOX Engineの `/audio_query` と `/synthesis` に送ります。既定は `http://127.0.0.1:50021` です。別PCのURLを設定した場合は、そのPCへ送信します。ナレーションが有効な場合は通常の説明文も対象になります。

接続確認に `/version`、話者一覧に `/speakers`、画像表示に `/speaker_info` を使います。独自の分析・広告・遠隔ログ送信はありません。音声・画像は再生や表示のためメモリに保持します。

利用者が話者チェックを実行すると、短い共通文を各スタイルの `/audio_query` と `/synthesis` に送り、合成できるか確認します。合成音は再生・保存しません。

## 保存

Chromeのローカルストレージに、自動読み上げ設定、接続先URL、出力機器ID、話者一覧、配役設定、会話ごとの配役・登場人物名・別名、発音辞書、感情演出設定、パネル表示設定・位置を保存します。会話IDを保存キーに使う場合があります。

話者チェックの実行日時・スタイルごとの成否・APIエラーの先頭部分も、接続先ごとにローカル保存します。再チェック完了時に結果を置き換え、利用者による中止・一覧取得失敗では以前の結果を保持します。

会話本文そのものを永続保存する処理はありませんが、配役の登場人物名や利用者が登録した辞書には会話由来の情報が含まれ得ます。タブごとの自動読み上げ状態・識別子はセッションストレージに保存します。取得本文・再生待ちテキストは動作中のメモリに保持します。

配役のJSONエクスポート、本文・診断情報のコピーは利用者の操作時に実行します。診断情報には会話URLなどが含まれるため、共有前に確認してください。

## 権限

| 権限・対象 | 用途 |
| --- | --- |
| `activeTab` | 利用者が開いた会話タブとの連携 |
| `scripting` | 古い取得処理の検出時などのページ内処理の導入 |
| `offscreen` | ポップアップを閉じても続く音声再生 |
| `storage` | 設定・配役・辞書等の保存 |
| `https://chatgpt.com/*` | コンテンツスクリプトで応答を取得 |
| `http://127.0.0.1:50021/*` | 既定のVOICEVOX Engineへの通信 |
| 任意のHTTP／HTTPSホスト（追加許可） | 接続先変更時、指定したホストへのアクセスを利用者に要求 |

機器一覧の取得ではChromeのマイクアクセス許可を求める場合があります。取得した音声ストリームは直ちに停止し、録音・送信は行いません。

# 0.7.5 作業内容と検証

## 変更内容

- 音声合成と再生を分離し、再生中に後続のセリフを合成する方式へ変更。
- 先読みは合成待ち・合成中・合成済みを合わせて最大3件。合成通信は同時実行せず、キューから1件ずつ順番に実行。
- 再生順、停止・一時停止・再開・スキップ、ランダム配役のエラー時再抽選と固定配役のスキップを維持。
- 停止時は先読みも中断し、待機音声と再生用URLの参照を解放。接続先が変わった場合は旧接続先の先読み音声を破棄して再合成。
- 話者の事前チェックとチェック結果による配役からの除外を一時停止。設定画面の操作とスクリプト読み込みを外し、保存済み結果も配役に使用しない。
- リモートAPIの画像取得を60秒まで待機し、メンバー一覧では1件ずつ取得。画像取得で再生操作が待たされないよう処理を分離。
- 試聴失敗時に話者名・スタイルID・失敗したAPI・エラー本文を表示。
- 停止中の事前チェック実装は将来の見直し用に保持。通信失敗の判定不能扱いと通信間隔の調整は、現在の実行経路には読み込まない。

## 検証

- Windowsの一時Chromeプロフィールで `tests/regressions.ps1` と `tests/settings.ps1` を実行。
- 再生中の先読み、3件の上限、通信の直列実行、FIFO、先読みの中断・解放、接続先切替をモックで検証。
- 通常利用時の再抽選とスキップ、事前判定の無視、画像取得が5秒を超える場合、画像待ち中の再生操作、試聴の500エラー表示を検証。
- バージョン表記、参照アセット、公開対象ファイルの整合性を確認。

リモートAPIへの少数の確認では、画像取得に5秒以上かかることと、拡張を介さない合成でもHTTP 500が返ることを確認しました。ユーザーによる調査ではAPI側のGPUメモリ不足が原因と判明しています。この拡張はサーバーのモデル解放処理を変更しません。今回の先読み方式について、実際のChatGPT画面・GPU・音声機器での通し確認は未実施です。

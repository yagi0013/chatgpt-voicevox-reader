# 公開準備の検査結果

対象：0.7.3。ローカルでのGitHub公開準備であり、リポジトリの作成・push・Release公開は未実施です。

## 整理したもの

- 個人PCの絶対パスと個人向けの呼び名を、公開用文書・会話例から除去。
- 特定のイヤホン名を使った案内・テストデータを一般化。
- `chrome-extension_bak/` とPythonキャッシュを追跡対象から除外。実ファイルは保持。
- `.gitignore` と `.gitattributes` を追加。
- MITライセンス、README、プライバシー・権限説明、開発・公開手順を整備。
- 拡張機能の説明を現在の機能に合わせて更新。
- GitHub Actionsのテスト設定、公開用ZIP生成スクリプトを追加。

## 検証

- GJSによるJavaScript構文・解析・配役・再生制御・出力先・復帰テスト：成功。
- Chromeによるメニュー・設定・画像付きメンバー一覧・検索・試聴テスト：成功。
- パネルの表示、操作、移動、状態問い合わせ間隔、画像キャッシュテスト：成功。
- 配布ZIPの整合性、参照アセット、READMEとmanifestの版数一致：成功。
- ZIPにGit履歴、バックアップ、キャッシュが含まれないこと：確認。
- 秘密鍵ヘッダー、GitHubトークン、AWSアクセスキーの代表的な形式を既存Git履歴で検索：検出なし。

パターン検査は秘密情報の不在を完全に証明するものではありません。外部サービスでのセキュリティ監査や、全キャラクター個別規約の適合審査は行っていません。

## 残る注意点

旧READMEの個人PCパスや旧バックアップは過去のGit履歴に残ります。公開用ソースZIPから新規リポジトリを作れば、その履歴を含めずに公開できます。コミット作者名・メールアドレスも公開前に確認してください。

実際のChatGPTの画面構造、VOICEVOXの各バージョン、全OS・全音声機器での動作を保証するものではありません。GitHub Actionsの実行結果は、GitHubへ公開するまで未確認です。

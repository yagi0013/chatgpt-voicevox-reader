# 0.7.4 作業内容と検証

## 変更内容

- 設定の「音声出力」に全話者・スタイルの使用可否チェックと中止ボタンを追加。
- 短い共通文で音声クエリと合成を確認し、失敗時は別の短文でも再確認。
- 結果・確認日時・エラーを接続先ごとに保存。再チェック完了時に更新し、利用者による中止・一覧取得失敗では以前の結果を保持。
- 使用不能なスタイルをランダム配役から除外。標準スタイルが使えない場合は使用可能な別スタイルを選択。
- 通常利用中にランダム配役の合成が失敗した場合は、失敗した話者を除外して再抽選し、同じセリフを再試行。配役を会話に保存し、後続の同じ配役にも反映。
- 固定配役の失敗と再抽選候補の枯渇は、そのセリフだけをスキップして後続を継続。
- 閉じられていないカギ括弧があっても、その後の完成したセリフを検出。
- 重複した拡張機能フォルダと追跡済みPythonキャッシュを整理。
- 公開用ファイル、プライバシー説明、Windows向け回帰テストとCIを整備。

## 検証方法

話者チェックはHTTPエラー・通信エラー・タイムアウト・不正なJSON・空音声が発生しても、そのスタイルの結果に記録して後続を確認します。失敗時は別文でも再確認し、両方失敗したスタイルを除外します。利用者の中止操作以外で個別の失敗がチェック全体を止めないことを回帰テストで確認します。

- Windowsの一時Chromeプロフィールで `tests/regressions.ps1` と `tests/settings.ps1` を実行。
- JavaScript構文、解析、配役、再生キュー、設定画面、話者チェックと再チェック、中止、接続先の分離をモックAPIで検証。
- バージョン表記、参照アセット、公開用ファイルの許可リスト、作業フォルダと公開用コピーの一致を確認。

実際のVOICEVOX・ChatGPT・音声機器での動作確認は未実施です。短文での合成成功は、すべての文章での成功を保証しません。GitHub Actionsの結果はPush後に別途確認します。

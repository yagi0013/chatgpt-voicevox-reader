# GitHub公開手順

## 公開用ファイル

```bash
python3 scripts/build_release.py
```

`dist/` に拡張機能用ZIPとソース用ZIPを生成し、SHA-256一覧を出力します。ZIPは明示したファイルだけを含み、`.git`、ローカル設定、バックアップ、Pythonキャッシュを含みません。画像・音声データも同梱しません。

拡張機能用ZIPは展開してChromeへ読み込みます。ソース用ZIPは新しい公開リポジトリの初期ファイルにも使用できます。

## 既存履歴について

このプロジェクトの古いGit履歴には、個人PCの絶対パス、会話例の呼び名、旧バックアップ、Pythonキャッシュが含まれています。現在のファイルを整理しても過去コミットからは消えません。

個人の作業履歴を公開する必要がない場合は、ソース用ZIPを別フォルダーへ展開し、新しいGitリポジトリの最初のコミットとして公開してください。既存リポジトリの履歴を書き換える処理は、この整理では行っていません。

Gitのコミットには作者名・メールアドレスも含まれます。新しいリポジトリでコミットする前に、公開したい名前・メールアドレスを確認してください。ZIP自体にGit履歴はありません。

## 公開前の確認

- READMEの導入手順、LICENSE、プライバシー説明を確認する。
- 自動テストと実機確認を実行する。
- 配役JSON、辞書、会話ログ、秘密鍵、認証情報を追加しない。
- スクリーンショットに会話内容や個人情報が写らないようにする。
- キャラクター画像・生成音声の公開には、それぞれの利用規約を確認する。

GitHubリポジトリの作成、push、Release公開は別の操作です。このスクリプトはローカルZIPの生成だけを行います。
